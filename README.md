# msc_geomatique
Codes développés lors d'une maîtrise en Sciences Géomatiques

## CALIBRATION_SPHERE

MATLAB codes to calibrate boresight and lever arms for a mobile LiDAR system using target spheres

## PLANE_RAYTRACING

MATLAB codes to create synthetic LiDAR scans on planes

## SPHERE_RAYTRACING

MATLAB codes to create synthetic LiDAR scans on spheres

## VLP16_GEOREF

Python codes to georeference VLP-16 data to UTM19 and HT2_1997
